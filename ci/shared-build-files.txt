# any of them starts the macOS and Windows lanes. ci/test_shared_build_files.py
# keeps this list exact, so the set only shrinks (#3237, tracker #3232).
#
# Adding a file here is a decision: first try a per-OS file (cmake/<os>/,
# libobs/cmake/os-<os>.cmake, rust-os-<os>.cmake, a src/platform/<os>/ module)
# or a per-unit fragment (libobs/build/ported-source-sets/, source-sets.d/,
# rust-hidden.d/, rust-exports.d/, test/cmocka/tests.d/). If it must be
# shared, add it in sorted order with a trailing "# reason". A new crate's
# build.rs or src/platform/mod.rs is shared by design.
