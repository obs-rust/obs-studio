Each accessor port adds `<port>.json` here. The object keys are explicit Rust-static target names. Values map target array fields (for example `sources`, `header_libraries`, `libraries`) to exact additional values, using the native graph JSON syntax for conditional requirements. Entries are discovered by sorted filename and appended with first-occurrence deduplication. Never copy expectations from the graph at test runtime.

New characterization cases add one `cases/<family>/<test-base>.json` containing a complete independent native graph with one target and one test. The filename must match `<test-base>_rust`. The source, header, decision, monitor and transition-start selection, CMake replay and unchanged-runtime checks discover the same case files. Conversion and pacing preserve their original singleton selection/runtime fixtures; adding another case in those families is rejected until their runtimes are extended. Every archive-linked graph target must have a case file; deleting a case is an error.

Do not edit a shared Rust list or another port's entry to register a new port. If two ports need a common stub or library, each declares it; identical values are included only once. Array order is exact and follows case values then sorted port entries. Scalar changes (including requirements) belong to the owning case file.
